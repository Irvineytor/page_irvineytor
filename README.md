# Portfolio de Irvin Aguirre

Primer prototipo de mi portfolio web.

## Archivos

- `index.html`: contenido y estructura de la página.
- `styles.css`: diseño adaptable a celular, tableta y escritorio.

## Pendientes

1. Confirma las fechas y nombres de puestos de CV, en especial la estancia en Sist3c.
2. Revisa que se va a mostrar públicamente el correo que aparece en los botones de contacto.
3. Sustituir o complementar los casos con enlaces a repositorios, demos o imágenes propias cuando estén disponibles.
4. Que el CV sea descargable, colocar una versión pública y depurada del PDF en esta carpeta y agrega un enlace; el sitio no publica el archivo personal automáticamente.
5. La tipografía usa Google Fonts. Hay que evaluar como funciona el sitio con esas fuentes, de lo contrario; eliminar el enlace a Google Fonts del encabezado y dejar las fuentes alternativas del sistema nativo.

El diseño es independiente del servidor: sirve con Apache o Nginx como archivos estáticos. No contiene formularios, rastreadores ni dependencias de ejecución.
